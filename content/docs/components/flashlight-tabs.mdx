```tsx

  return <FlashlightTabs />;
}
```

## Features

- **Flashlight glow**: A soft white glow follows the selected tab along the bottom edge.
- **Spring-based transitions**: Tab background and glow animate with smooth spring physics.
- **Responsive**: Automatically shows fewer tabs on mobile screens.
- **Text shadow**: The active tab gets a subtle luminous text shadow.
